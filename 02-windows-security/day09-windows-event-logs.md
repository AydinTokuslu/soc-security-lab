# Day 9 — Windows Security Event Log Analysis

## 1. Objective

Investigate Windows Security Event Logs to identify authentication activity, process creation, user account creation, and security group membership changes.

## 2. Lab Environment

- Windows 10 Pro domain-joined workstation
- Windows Server 2025 Domain Controller (DC01)
- Active Directory domain: corp.example.test
- Tools: Windows Event Viewer, PowerShell, auditpol

## 3. Authentication Analysis

Investigated the following events:

- Event ID 4624 — Successful Logon
- Event ID 4625 — Failed Logon

A controlled incorrect password attempt generated Event ID 4625.

Observed evidence:

- Account: DESKTOP-5NH986E\aydin
- Logon Type: 2 (Interactive)
- Status: 0xC000006D
- SubStatus: 0xC000006A (Incorrect password)

Successful authentication events were also reviewed, including interactive, unlock, service, and network logon activity.

## 4. Process Creation Analysis

Enabled Process Creation auditing using auditpol.

Event ID 4688 was generated by launching Notepad and CMD from PowerShell.

Observed evidence:

- Parent Process: powershell.exe
- Child Processes: notepad.exe, cmd.exe
- Command Line: cmd.exe /c whoami

Command-line logging was enabled through Windows Registry configuration.

## 5. Active Directory Account Creation

Created a disabled test user in Active Directory.

- Event ID: 4720
- Subject: CORP\Administrator
- New Account: CORP\soc.lab.test
- Account Status: Disabled

The event confirmed that the Domain Controller recorded the new account creation.

## 6. Security Group Membership Change

Created a test Global Security Group and added the test account.

- Event ID: 4728
- Subject: CORP\Administrator
- Member: soc.lab.test
- Group: SOC-Lab-Security

The account SID matched the SID observed in Event ID 4720, allowing the two events to be correlated.

The test group did not grant Domain Admin privileges.

## 7. Security Assessment

**Classification: Benign — Authorized Lab Activity**

All activities were deliberately performed in an isolated security laboratory.

The exercise demonstrated how authentication events, process creation, account creation, and group membership changes can be investigated and correlated.

## 8. Key Lessons Learned

- Event ID 4624 identifies successful logons.
- Event ID 4625 identifies failed logons.
- Event ID 4688 records process creation.
- Event ID 4720 records user account creation.
- Event ID 4728 records membership additions to security-enabled global groups.
- Security events must be correlated using timestamps, accounts, SIDs, source information, and process context.
- A single event does not necessarily indicate malicious activity.
